PRODUCT TOUR

从一句话，到一顿饭。

下方均为 2026-09-17 的本地运行截图，使用高德 POI。商家数据随查询变化；价格、评分和距离仅供参考。

01 / 筛选有依据，选择更清楚

预算、区域与排除条件共同生效。切换区域自动刷新结果，卡片展示来源和未知信息。

02 / 看得到信息的边界

餐厅详情说明参考距离的起点，不将未知营业状态或过敏原信息当作确定事实。

03 / 沿着校园，画出查询范围

圆形、矩形或多边形圈选，JSON 导出，直接保存到后端。你定义范围，系统检查边界。

DESIGNED TO BE GROUNDED

模型理解需求，代码核验事实。

单 Agent 调用检索、详情、比较和条件建议工具。表单与对话共用筛选规则，候选 ID、预算和信息来源由后端校验。

这是静态展示页，不会调用模型或查询商家。完整应用需要本地 Python 后端；不配置 Key 时可以用表单体验标注清楚的模拟数据。实时营业、过敏安全与实际路线不在当前保证范围内。
